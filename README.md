# Maixiangyuan

Website for Maixiangyuan (麦香园), a dumpling restaurant on Mont-Royal in Montréal. Trilingual (FR / EN / 中文), French first.

Planned: online takeout pre-orders (paid in store), reservations, reviews, a dumpling loyalty card, and an owner dashboard. The restaurant's POS stays the system of record for sales; this site never handles payments.

## Dev

```bash
npm install
npm run dev
```
